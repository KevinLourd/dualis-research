## Data convention: bronze / silver / gold (every dimension)
One Postgres schema per layer (`web/src/db/schema/`). A **dimension** = one kind of data (watchlist, company profile, news, filings...).
- **bronze.fetches**: the raw answer of EVERY fetch, failures included (source, subject, request WITHOUT secrets, http status, payload / payload_text, error, run id). Append-only, one table for all dimensions.
- **silver**: canonical rows built ONLY from bronze by the dimension's `promote`. Attribute data ("field = value") goes to the generic **silver.facts** (dimension, subject, field, value, `sources[]`, `bronze_ids[]`); an entity with its own identity (news item, filing, event) gets its own silver table with a natural key and a `sources text[]` column.
- **Provenance rule**: a value several sources agree on is ONE row carrying EVERY source tag, never first-found (`src/bsg/provenance.ts`: `applyAssertions`, `pickWinner`: Thierry's manual value > most sources > source priority).
- **gold**: what the console reads, rebuilt from silver by the promoter (`gold.tickers`, `gold.company_profiles` + per-field `provenance`).
- **ops.runs / ops.run_sources**: one row per run, one per source (status ok / partial / failed / skipped, counts, first 20 errors, duration). The Data page shows them.
