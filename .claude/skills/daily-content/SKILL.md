# Daily content loop

**Cadence**: 2 posts/day, each published on Substack Notes AND X (adapted per platform).

**Morning message to Thierry** (WhatsApp or equivalent): 2-4 drafts, each with source link + which watchlist ticker/driver it comes from. He approves, edits or skips. Nothing publishes without his OK.

**Where drafts come from** (priority order):
1. A signal (Thierry 2026-11-04): an indicator that a narrative is cracking / inflecting, as its chart + why, ready as a Note. Never post or comment in his name with generic AI text (he hates AI comments).
2. A chart or figure from a recent note.
3. A market-wide take tied to a thesis.

**Post shape**
- X: hook line with the number or claim, 1-3 lines context, chart if any.
- Substack Note: same idea, slightly longer.
- **No Substack link or CTA in the post**: the profile bio of each network carries the link + a subscribe CTA (Kevin 2026-11-04); check the bio, not the post.
- Every post grows the funnel: follower → free subscriber → paid subscriber.

**Note format = Multibagger Ideas** (@multibaggerideas, 42K subs, 515 paid, ~$1M/yr; Thierry 2026-11-09 « copy aspects of his posting »): one Note a day, 5-8 one-sentence lines, blank line between; opens on a number or a one-line claim; one maths fact made visual (emoji bars, a decade table); a named real case (Buffett, Amazon); closes on « The point: » / « The maths: » + one line. Each post gets a teaser Note (company unnamed + 3 figures + « wrote it up today for subscribers »). Milestones posted as plain facts (views, readers, paid). Posts: Monday/Friday rhythm, figure-led titles (« 20% Recurring Revenue Growth, Record Customer Wins, Down 56% »), recurring portfolio updates, closed calls with their % (« Thesis Closed at +81% »).
**Other references**: Kobeissi Letter, Unusual_Whales (speed, numbers first), Citrini, Aurelion (depth). See `docs/references.md`.

Log every published post in `docs/daily-log.md` (date, platform, link, ticker).
