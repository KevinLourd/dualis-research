# Logos

The Dualis mark (chosen by Kevin 2026-11-05): the **D of Dualis, split by a price line that dips, then turns up**. Two sides in one letter (long and short), and the moment a narrative turns. Built with the logo-design skill (kaankiziltug/logo-design-skill): concepts, 16 px tests, then this kit.

- `dualis-mark.svg`: master, `brand` navy, 256 grid.
- `dualis-mark-black.svg`, `-white.svg` (on navy or dark), `-mono-5b3fd6.svg` (purple accent), `-square.svg`, PNGs at 1024.
- `dualis-avatar.svg` / `.png`: Substack and X profile picture (white mark on navy, survives the round crop).
- Web icons (favicon.ico, favicon.svg, apple-touch-icon, icon-192/512) live in `site/public/`.

Rules: one colour at a time (navy, white, or purple), never outlined text beside it in another colour, clear space = the outline's thickness on every side, minimum 16 px.
