# BullBear

Two columns side by side, bull on the left and bear on the right: the Dualis signature section of every note.

- Markup: `.dr-bb` with `section.bull` and `section.bear`, each an `h4` and a `ul` of 3 to 5 points.
- Same number of points on each side when possible. Each point is one sentence with a measurable claim.
- Stacks to one column under 520px, bull first.
